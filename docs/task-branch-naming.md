# Task Branch Naming Convention

## Format Wajib
`feature/<task-id>-<slug>`

Contoh:
- `feature/t001-repo-governance-baseline`
- `feature/t006-session-auth-foundation`
- `feature/t017-theme-settings-module`

## Aturan Tambahan
- Satu branch hanya untuk satu task.
- Jangan gabungkan beberapa Task ID dalam satu branch.
- PR title harus menyebut Task ID.
